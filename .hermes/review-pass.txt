## 1. AGENT-REVIEW — bugs, edge cases, invariants

### Changed: src/Hive/Hive.php:589-597
Adds 9 lines in `doDiscoverTick()`: after heldout/raw discover, calls 
`AtomRegistry::discoverCompose($X, $y, $composeGrammar)` with a fresh grammar 
snapshot from DB, filters by `$cvTrainMax`, and records via `recordDiscovery()`.

### Edge cases analysed:

**(a) Grammar freshness**: `(new Grammar())->all()` creates a fresh instance 
reading from DB. Since `recordDiscovery()` (called by heldout/raw path above) 
writes to DB immediately, newly discovered atoms ARE visible to compose. ✓

**(b) Redundancy with doComposeTick()**: `doComposeTick()` (line 631) is only 
called under plateau/desperation conditions. The new eager compose in 
`doDiscoverTick` runs on EVERY tick after the heldout/raw block. Duplicate 
check in `recordDiscovery()` (line 603, `$this->knownLaws` key) prevents 
double-insertion. Harmless redundancy. ✓

**(c) CV threshold**: `discoverCompose()` internally returns only `cv < 0.001` 
atoms, so the `$d['cv'] <= $cvTrainMax` guard is currently redundant but 
defensively correct — mirrors the raw discover path and respects null-calibrated 
epsilon. ✓

**(d) Empty X / insufficient data**: Block inherits statistical sufficiency 
check at top of doDiscoverTick (line 532-537). $X and $y guaranteed valid. ✓

**(e) count($composeGrammar) >= 2 guard**: Prevents wasted O(n²) pair iteration 
when grammar has < 2 atoms. ✓

### Invariants preserved:
- No modification to task, $X, $y, $domain state
- `$foundAny` propagated correctly through recordDiscovery
- `$this->knownLaws` cache consistent via key-based dedup

## 3. STRATEGIC GATE

**Assessment: Sound.**

The eager compose path ensures composite atoms are discovered alongside basic 
atoms on every tick — not just under plateau or desperation conditions. This 
increases discovery throughput.

The dual path (eager in doDiscoverTick + conditional in doComposeTick) is 
acceptable: `recordDiscovery` deduplication prevents any double-counting or 
double-insertion.

`discoverCompose` pre-filters to `cv < 0.001`, so quality bar is actually 
higher than the `$cvTrainMax` threshold allows. No risk of low-quality compose 
atoms polluting grammar.

The test `testHiveDiscoversComposeAtom` validates end-to-end mechanism: seed 
grammar → discoverCompose → abs(sub) found. Coverage is adequate for Phase 1.

**No strategic concerns.**

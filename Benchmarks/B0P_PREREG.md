# B0-P: Composition of Functional Patterns — ПРЕДОПРЕДЕЛЕНИЕ
# (заморожено до оценки holdout)

Дата заморозки: 21.11.2026. Новая постановка после B0: не предсказывать
тройной генетический эффект из первых моментов свойств генов (это

КОМПОЗИЦИИ ФУНКЦИОНАЛЬНЫХ ПАТТЕРНОВ участников.

## Слои данных (не смешивать; связка только по идентификаторам)

A. Kuzmin 2018 (Science aao5670; Zenodo 4966554): тройные композиции.
   Целевая величина: собственный пересчитанный τ_SGA
   (τ = f_abc − f_ab·f_c − f_ac·f_b − f_bc·f_a + 2·f_a·f_b·f_k),
   64356 троек с полными нижними порядками.
B. Costanzo 2016 (Zenodo 4959345): глобальные парные профили —
   вектор взаимодействий каждого гена со всей панелью. 17.1M пар,
   SMF, degree. Из профилей строится библиотека паттернов.
C. YeastCoDEGNet / Costanzo 2016 environmental: смена контекста
   (14 условий) — слой P5, подключается ПОСЛЕ основного теста.
   GSE278267 — иллюстрация, не бенчмарк.

## Определения

- ПАТТЕРН = кластер генов с близкими профилями парных взаимодействий
  (профиль = вектор ε гена против панели). Кластеризация — на train-
  генах ТОЛЬКО. Библиотека паттернов строится без доступа к holdout-
  композициям.
- КОМПОЗИЦИЯ = мультиграф паттернов тройки: (P(a), P(b), P(c)) +
  признаки их отношений (совпадение паттернов, размер паттернов,
  mean/max сходство профиля c-гена к паттерну пары).
- РОЛЕВАЯ ЭКВИВАЛЕНТНОСТЬ (P2): ген x эквивалентен гену y в контексте
  тройки, если τ_SGA(a,b,x) и τ_SGA(a,b,y) дают согласованное
  смещение против базового предсказания при замене.

## Модели (заморожены)

| Модель | Признаки |
|---|---|
| B0-база | первые моменты (SMF/ess/degree/neg) — уже известно: ≈ identity |
| P-1 | индикаторы паттернов участников (pattern X + pattern X + pattern Y) |
| P-2 | P-1 + межпаттерновые признаки (сходство профилей, размеры) |
| P-3 | P-2 + парные eps тройки (a,c),(b,c) — НЕ считаем открытием: алгебра в τ (контроль тавтологии обязателен) |

Первичная метрика: RMSE на holdout из ЦЕЛЫХ query-пар, невиданных
в train (пересечение: ни пары, ни её генов-партнёров в train-композициях
третьими генами по возможности). Блок-bootstrap по query-парам.

## Контроли (все сохраняются)

1. Shuffled patterns: перестановка паттерн-меток между генами
   (сохраняя размеры кластеров) — null для P-1/P-2.
2. Identity: индикаторы генов (уже построен в B0).
3. Тавтология-контроль: P-3 оценивается отдельно и помечается
   как «алгебраическая граница», не как находка.
4. GO-декодирование: найденные паттерны сверяются с GO/SGD-аннотациями
   ПОСЛЕ кластеризации — если паттерн = известная GO-категория 1:1,
   это честно фиксируется (проверка «не переизобрели ли аннотирование»).
5. Структурные nulls: топология-сохраняющая перестановка профилей.

## Успех (лестница P1–P6)

P1: повторяющиеся паттерны найдены и устойчивы к выкидам генов.
P2: ролевая замена участника внутри паттерна сохраняет характер
    смещения τ (корреляция смещений > 0 при замене; против null).
P3: композиции паттернов предсказывают τ на невиданных query-парах
    лучше identity-модели (ΔRMSE CI не включает 0).
P4: результат воспроизводится на втором сплите (обратный holdout).
P5: устойчивость при смене среды (слой C, отдельно).
P6: границы применимости (по типам паттернов/условиям).

ОТКАЗ = если P-1/P-2 на holdout не лучше identity И паттерны
вырождаются в GO-категории — B0-P фиксируется как отрицательный
результат с границей мощности, кампания по «композиции функций»
закрывается с мета-выводом.

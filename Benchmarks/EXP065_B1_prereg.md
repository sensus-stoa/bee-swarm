# EXP-065 / Блок B1: mark-chain positive control на честной дороге

**Статус: FROZEN 17.11.2026 — rev.2. Воркеров: 8 (owner 17.11).**

## Амендмент B1.1 (17.11, отладочный блок по итогам B1)

Результаты B1 (30 прогонов): нуль чист (0/10); A ≈ B (3/10 обе, McNemar p=1.0);
тёмные сиды 502–505 — **L0 ✓ (доноры пишутся), L1 ✓ (доноры в пуле до 8/проход),
L2 ✗ (мерж не срабатывает)** — бутстрап-граница локализована на шаге компоновки,
не в логистике дороги. Инфра-баг: **детерминизм сломан** — бюджет полёта
wall-clock (12s), под нагрузкой 8 воркеров траектории расходятся (смоук B/502
сертил C@7, полный прогон того же слота — нет). Прежняя «детерминированность»
exp063 — совпадение условий нагрузки, не свойство.

B1.1 (последовательно, P=1, только тёмные сиды 502–506, нуль не гоняется):
- **(a0) chain flags-off** и **(a1) chain W+R on**: 8 проходов × 12s — контроль
  бага (диверсия помогает/вредит цепочке; проб поймал аномалию: honest
  однопроходно 1/10 < starved 4/10 — подозрение на вытеснение партиала из
  mid-ladder USE_MARKS);
- **(b) lottery**: 8 независимых попыток × 12s, каждая с чистой дорогой,
  соли различны — «8 лотерейных билетов» против «8 проходов с памятью»;
- **(c) long-flight**: 96s одним проходом, без дороги — время vs память.
- Равный бюджет 96s у всех; повтор 502/A1 в конце = контроль детерминизма.

Интерпретация:
- a-best решает, b/c нет → дорога добавляет ДОСТИЖИМОСТЬ (ядро кампании);
- b или c решает → движку хватает бюджета/дисперсии, дорога = ускоритель;
- никто не решает → компоновка недостижима всеми путями → forensics мержа
  (почему pair-merge не срабатывает при донорах в пуле).

Причина: смоук rev.1 (pure3 `x0·x1·x2`) показал однопроходный серт на первом же
проходе — инстанса в конверте (алгебраическое тождество `(x0+x1)×C − (x0−x1)×C`),
цепочка не упражняется. Конверт-проб (одиночный проход, 12s, сиды 501–510):
pure3 = 5/5 сертов; pure4 starved = 4/10 (светлы 507–510), honest = 1/10
(светл 501); **тёмные в обоих конфигах: 502–506**.

Изменения:
1. Инстанса: `y = x0·x1·x2·x3` (pure4 — канон EXP-045 four-product law).
2. Сиды 501–510 целиком (10): светлые 507–510 = гейт валидности харнеса,
   тёмные 502–506 = тест цепочки, 501 = пограничный.
3. Пороги H1'/H2' переопределены (см. ниже); канонического порога для
   самобутстрапа цепочки без ручного материала не существует (канон EXP-045
   22/24 — с ручным материалом), поэтому исход «обе руки ≈ 0 на тёмных» —
   валидный научный результат (граница самобутстрапа), не отказ инфраструктуры.
4. Урок: конверт зависит от конфигурации — отбор сидов процедурный, в обеих
   конфигурациях (starved И honest).

## 1. Контекст и место в кампании

- §7.x статьи: mark-chain компонирует без градиента корреляции (pass 1 = партиал
  0.667, проходы 2–8 сертифицируют там, где 200 однопроходных форм маршрутов
  дают 0). Канон: 7/8.
- EXP-064 (наш, 17.11): root cause голодания дороги на записи (кап ROAD V4 +
  захват слотов семейством контаминации); фикс TRAIL_WRITE_DIVERSITY +
  TRAIL_READ_DIVERSITY; пилот cdeep2 8/8 на свежих сидах против 0/2 контроля.
- **B1 — минимальный блок**: внутри-задачная цепочка (pass 1..8, одна инстанса,
  дорога живёт в процессе). Вопрос: честная дорога не ломает mark-chain?
- B1 НЕ заявляет: cross-task перенос (B2), вне-конверт (B3), накопление
  компетенции (B4). Каждый следующий блок — отдельный амендмент пререга.

## 2. Задача

Чистое трёхфакторное произведение (класс PRODUCT, pureprod), синтетика:

    y = x0·x1·x2,  фичи x0..x4, n=200, noise=0, seed-канон exp063 (LCG s=seed+555)

Однопроходный потолок = 2/3 факторов (партиал 0.667); корреляция партиала
с y ≈ 0 (математика zero-mean, на heat-инстансе статьи: −0.14/−0.11/−0.20).
Полный закон достижим ТОЛЬКО через дорогу: метка (x0×x1), прочитанная pass 2,
мержится с родителем x2 → полный закон (канон WU-4c: метка⊕родитель = закон).

Инстанса одна (canon-инстанса §7.x = heat-класс); вариативность — по сидам
данных и маршрутов, 15 сидов (канон репо).

## 3. Руки (3 × 15 сидов = 45 прогонов)

| Рука | Флаги | Смысл |
|---|---|---|
| A. starved | off | канон-репликация: харнес обязан воспроизвести §7.x |
| B. honest | W+R on | вопрос блока: диверсия не ломает цепочку |
| C. null | W+R on, shuffle(y) | нулевая валидация в блоке: ожидаем 0 |

Прогон: 8 проходов над одной инстансой, SWARM_DB_PATH=:memory: (дорога живёт
в процессе), route-лестница = канон exp063 (USE_MARKS → FLIGHT × 2, K=5,
beam10nl d=2), бюджет 12s/проход. Однопроходный базовый уровень берётся из
телеметрии pass 1 тех же прогонов (отдельная рука не нужна).

## 4. Метрики (каскад, для телеметрии и отладки)

- **L0** — донорские ранги записаны в дорогу к началу pass k (`trail.written`)
- **L1** — донорский терм в `read_injected` пула pass k
- **L2** — серт к проходу k (первичный): cert к pass ≤ 8; индекс первого серта
- Изоморфизм `cert_form` закону (cert_v2 = exact-check, обязателен)
- junk-доля written (cancellation (A−B)+B) — телеметрия, гипотез не несёт

## 5. Гипотезы и пороги (замораживаются до запуска)

- **H1 (валидность харнеса, рука A):** сертов ≥ 12/15 сидов к pass 8, И
  pass 1 в одиночку сертифицирует ≤ 2/15. Провал → СТОП кампании, отладка
  инфраструктуры (сверка с §7.x: канон 7/8).
- **H2 (вопрос блока, B против A):** попарно по сидам, McNemar exact;
  B ≥ A − 1 серт. Бонус (не гейт): медиана индекса первого серта B ≤ A.
- **H3 (нуль, рука C):** 0/15. Любой серт → гейт пропускает мусор → СТОП,
  forensics гейта до продолжения.

## 6. Триггеры быстрого возврата к отладке (frozen)

1. H1 провален → camпания не стартует в B/C; forensics каскадом L0→L1→L2.
2. B < A на ≥ 3 серта → СТОП: диверсия рвёт цепочку; разбор, на каком уровне
   (L0 записалось меньше? L1 не читается? L2 не мержится?).
3. C ≥ 1 серт → СТОП: null-протечка.
4. Любой прогон > 3× медианы wall → расследование до интерпретации.

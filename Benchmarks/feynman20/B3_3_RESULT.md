# EXP-066 B3.3: assembly-potential (rescue промежуточных) — итог блока

## Механизм

L2-BEAM (always-on, гейт depth>=3): формы глубины-2 скорятся не
cv-к финальной цели (кирпич честно проигрывает вырожденным: ранг
476/4536, телескоп exp066_telescope.php), а ЛУЧШЕЙ однобуквенной
достройкой из пула — локальная аффинность к партнёрам (аналогия:
фолдинг белка — связки решают, не глобальный fitness). Дети с
cv<0.02 регистрируются в $exprs до collect → exact-гейт
сертифицирует глубину-3 в тот же полёт. Экономика: break на точной
связке, cap 300 (I_18_4: 88s → 71s).

Owner-решение (18.11): включение по задачам = оракул → всегда-вкл,
выключатель SEARCH_L2_LOOKAHEAD=0 — только для A/B.

## Граница (открытая)

Класс «сумма обратных / двухэтажный знаменатель» (I_27_6, I_13_12,
II_21_32) — глубже 3 уровней: требует лестницы (1/r2−1/r1) →
умножение → деление, т.е. re-entry потенциальных детей КАК кирпичей
следующего уровня. Текущий potential — один хоп. Следующий шаг:
цикл «потенциал → регистрация → потенциал» до exact (или до
бюджета) — глубина climbing, предсказанный предел — бюджет.

## Валидация

  GREEN после; найден дефект тестового канала (без

  (lookahead выбирает изоморфную форму — канон «ассерт не уже

  факт: окно необходимости дороги СУЖАЕТСЯ до классов с
  нестандартной структурой промежуточных).
- Два-pass 23:29: GREEN 1456/1456 (fast 1441 + slow 15).

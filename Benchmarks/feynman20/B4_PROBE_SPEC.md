# B4 SPEC: пробник необходимости (necessity probe) для батарейных ячеек

## Назначение

Классифицировать каждую ячейку батарейного набора по тому, ГДЕ
прямой перебор кончает сигнал, — БЕЗ знания целевого закона. Пробник
превращает «запустим и посмотрим» в каузально чистый отбор: ячейка
попадает в necessity-набор только если перебор доказанно бессилен
при зафиксированном бюджете → любой серт на ней обязан механизму
(дорога / potential-мост / climbing).

## Три состояния формы в конвейере (механика из телескопа B3.2)

1. **born** — форма рождена свипом (collect-all дамп pair-loop /
   L2L1 / potential-дети);
2. **survived** — доездила до collect-оценки (CAND-EVAL трейс);
3. **certified** — exact-гейт + cert_v2.

Граница между состояниями на слое глубины d = тип необходимого
механизма. Классификация БЕЗ целевого закона: меряем min-cv
по слоям (d1 сырые/пары, d2 pair-loop, d3 potential-дети).

## Классификация ячейки

| Профиль | Диагноз | Механизм |
|---------|---------|----------|
| cert на A0-прогоне | перебор справляется | движок; в necessity-набор не берём |
| min-cv низкий на слое d, формы слоя d+1 born но NOT survived | кирпичи есть, моста нет | potential-мост (I_18_4-класс) |
| потенциальные дети born, но слои дальше не рождаются | нужен climbing-цикл | depth climbing (I_27_6-класс) |
| ни на одном слое нет форм с cv ниже окна | грамматика не выражает | расширение грамматики / RCD |

## Процедура на ячейку

1. Данные: fade-curve → X, y; признаки (C-rate, DoD, T, cycles) →
   лейблы x0..xK.
2. A0-прогон: TRAIL_MARKS=0 (дорога off), TRAIL_BUDGET_MODE=steps,
   TRAIL_BUDGET_STEPS=5000 (щедрый, фиксируется в пререге), depth=3,
   SEARCH_DEBUG=1 + collect-all + survived-трейсы. Строго 2>файл.
3. Извлечение cv-профиля по слоям: min-cv среди born / survived /
   certified на каждом уровне.
4. Вердикт по таблице; одна строка jsonl: cell_id, класс,
   min_cv_по_слоям, wall, шаги, артефакт-дамп.

## Валидация пробника ДО батарей (positive/negative control)

- dot-задача (x0x3+x1x4+x2x4) и III_21_20 → обязаны дать
  «перебор справляется» (cert на A0);
- I_18_4 → обязан дать «кирпичи есть, моста нет» (известно численно:
  рождение 505, доезд 0);
- I_27_6 → ожидается climbing-класс (проверка предсказания);
- расхождение контроля → чинить пробник, не бенчмарк.

## Стоимость

Проба ячейки ~2–5 мин. Пилот 10 ячеек ~40 мин. Полные 273 —
10–20 ч, параллелизм 2–3 воркера (прогоны изолированы SWARM_DB_PATH=
:memory:; правило «≤1 тяжёлого процесса» НЕ нарушать вместе с two-pass).

## Ограничения (в пререг)

- necessity = «недостижима прямой генерацией при бюджете B=5000
  steps», не «в принципе»; изменение B = амендмент.
- Ложноположительное «перебор справился» исключено тройной проверкой
  born/survived/cert.
- Пробник НЕ улучшает механизм — он делает тест чувствительным
  (владелец, 18.11): улучшение механизма = отдельное решение ПОСЛЕ
  классификации, по доминирующему классу.

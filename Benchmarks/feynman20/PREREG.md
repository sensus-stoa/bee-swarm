# EXP-066 B3: синтетическая семья Feynman20 — пререг

## Вопрос
Распространяется ли механизм накопления (assembly + честная дорога,
включая нишевую квоту TRAIL_ADMIT_NICHE=1) на семью независимых задач
с известными частями и неизвестной сборкой — за пределами инстансов
EXP-065 (502–506)?

## Задачи (provenance)
20 датасетов семейства feynman_* из Penn ML Benchmark (pmlb, репозиторий
EpistasisLab/pmlb@master), источник — Feynman Symbolic Regression Database
(Udrescu & Tegmark 2019, arXiv:1905.11481).

Фильтр (механический, по формуле из metadata.yaml, без усмотрения):
1. Нет операций вне конверта: sqrt, exp, log/ln, sin/cos/tan, ** (>2).
2. ≥3 переменных (наличие парных доноров для сборки).
Результат фильтра: 119 → 37 (конверт) → 21 (≥3 перем.) → 20 (чистка ln
в feynman_I_44_4). Список: Benchmarks/feynman20/tasks.json.

## Данные
TSV pmlb → первые 200 строк (порядок файла), y = target, без шума.
Колонки переменных маппятся в x0..x{K-1} в порядке следования в файле.

## Дизайн
- Лестница: 2×(USE_MARKS k=5 + FLIGHT beam10nl depth2), 8 проходов,
  TRAIL_BUDGET_MODE=steps, TRAIL_BUDGET_STEPS=1500.
- Руки: A1 = niche=1 + WRITE_DIVERSITY=1 + READ_DIVERSITY=1;
  A0 = niche=0 + diversity=0 (голодная).
- L (лотерея) и T (долгий полёт 12000 steps) — только на задачах, где
  A1 сертифицировал (каузальное сравнение, как в B1.1).
- Сиды: seed = 701 + индекс задачи (алфавитный порядок списка).
  mt_srand(seed) + SEARCH_ROTATION_SEED=seed.
- Первичный исход: certs (cert_v2, 3 сплита 60/40, порог 0.10).
- Детерминизм: повтор A1 на 2 задачах — traj_sha обязаны совпасть.

## Предсказания (до прогона)
- A1 решает ≥8/20 (механизм перенесён с 502-класса: чистые произведения
  типа I_14_3 = m·g·z — структурный аналог 502).
- A0 решает <3/20 (голод дороги), L/T на решённых A1 — хуже A1 по числу
  сертов на единицу бюджета.
- Задачи с суммами в знаменателе/числителе (I_18_4, I_27_6) — кандидаты
  на новую границу (доноры = рациональные подформы, не голые пары).

## Запреты
Не менять грамматику/конверт/бюджеты между руками; не подгонять флаги
под результат отдельных задач; негативные исходы — в леджер без правок.

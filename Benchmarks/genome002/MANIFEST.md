## 3. Родители (одинаковые для трёх рук, req 1)

Родитель = цель с ОДНИМ структурным повреждением: kind ∈ {op_swap, atom_swap,
drop} (uniform по сиду), сайт = uniform по узлам соответствующего класса.
Повреждение применяется к ДЕРЕВУ — логический сайт один для всех рук.
Пересев сида повреждения, пока родитель некорректен (макс 20, детерминировано).
Сиды: 20261020+2000+i*97+s.

## 4. Словарь и pool (req 2-3, 9)

Train-семейство реплики: собственные PROPER subtrees цели (≥4 узлов, топ-3 по
размеру) × 2 случайных binding'а — модель «ранее открытых на других доменах»
конструкций (probe0-сценарий). Целая форма в train НЕ попадает → полезный
ремонт всей программы остаётся genuinely-new (не reuse).

Словарь реплики = GENOME-001 extraction (min 4 узла, ≥2 программ, cap 32,
порядок nodes DESC) по train-семейству; ЗАМОРАЖИВАЕТСЯ до прогона.
Pool рук A/C = ТЕ ЖЕ shape'ы без упаковки (одинаковая информация, req 2).
Стоимость словаря (байты bundle + parent-геном) учитывается отдельно при
полного-цикловом сравнении (req 9).

## 5. Мутации (req 5, сопоставимые)

Веса ОДИНАКОВЫ у всех рук: op_swap 0.30 / atom_swap 0.30 / splice 0.25 / drop
0.15; выбор uniform; базовые операции {+,−,×,/}; колонки x0..x5.

- A: op-swap (узел → другая базовая операция), atom-swap (атом → колонка),
  splice (узел → случайная shape'а pool со случайной привязкой), drop
  (узел → случайный атом).
- B: те же классы НАД ГЕНОМОМ; word-ref — единая единица: op-swap на ref =
  замена на другое слово ТОЙ ЖЕ арности (uniform), splice на ref = замена на
  другое слово; splice вне ref = вставка случайного слова со случайной
  привязкой аргументов к колонкам. Никаких интеллектуальных выборов — всё
  uniform (req 5).
- C: DAG с hash-cons; сайт = узел ТАБЛИЦЫ (uniform); общие узлы меняются во
  ВСЕХ вхождениях (семантика представления); splice = интернирование shape'ы.
  Копирование таблицы на потомка — PHP value-semantics.

Попытка с невозможным сайтом → re-roll внутри класса; совсем невозможная →
вёдро noop (бюджент попыток одинаков, эффективная отдача — часть измерения).

## 6. Полезность (req 6-8, заморожено)

- Корректность: offspring вычислим на всех 20 строках (конечные значения).
- Улучшение: rmse на HELD-OUT (8 строк) < rmse_held(родитель) − 1e-12.
- Novelty: functionKey (структура+атомы as-is, коммутативные сортируются)
  не встречался среди ранее порождённых потомков ЭТОЙ руки в этой реплике и
  родителя.
- Вёдра (по порядку): incorrect → correct_flat (нет улучшения) → reuse_shape
  (alpha-ключ offspring = alpha-ключу слова словаря — «голый инстанс готовой
  конструкции», req 8) → improved_not_novel → useful_new.
  Композиции слов в НОВУЮ программу — это тестируемый механизм, не reuse:
  reuse = только offspring, совпадающий с ОДНИМ словом целиком.
- Разбор: useful_by_op (какой класс мутаций дал полезного), ref_useful
  (у B — сколько полезных через ref-позиции: канал словаря).

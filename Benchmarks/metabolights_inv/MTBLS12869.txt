Study Title	Sertraline Hydrochloride Exposure Leads to Reactive Oxygen Species Burst in Model Microalgae Species (Raphidocelis subcapitata)
Study Description	<p>Microalgae play important ecological roles and serve as useful models for assessing impacts of environmental contaminants on lower trophic aquatic organisms. Sertraline, a commonly prescribed selective serotonin reuptake inhibitor (SSRI) found in urban waters, has been observed to induce chlorosis in Raphidocelis subcapitata close to environmentally relevant concentrations. This study estimated potentially hazardous concentrations of sertraline hydrochloride by deriving transcriptomic and metabolomic points of departure (tPODs and mPODs) below which chronic adverse effects would not be expected. Additionally, an Adverse Outcome Pathway describing the mechanism by which sertraline hydrochloride impacted R. subcapitata was proposed using a multi-omics approach. This data contains the raw and processed files of nontargeted metabolomics for extracted R. subcapitata metabolites after exposure to sertraline hydrochloride.</p>

Study Protocol Description	<p><em>Raphidocelis&nbsp;subcapitata</em> were purchased from Carolina Biological Supply (Catalog 152520 Burlington, NC, USA) and reared in Woods Hole MBL media at 24 °C with constant light (∼250 µmol/m2/s). <em>R. subcapitata</em> (5 x 10^6 cells/mL) were exposed to nominal concentrations of 50, 125, 314, 784, 1,960, 4,900, 12,250 and 30,620 µg sertraline/L (CAS:79559-97-0) or solvent control (0.01% DMSO) for 24 h in 4 replicate, 96-well deep-well (2.0 mL) plates using 800 µL of solution per well (Catalog 267007, Beckman Coulter, CA, USA) sealed with optically clear adhesive covers (BEM-1, Diversified Biotech, MA, USA). There were 5 replicate wells per treatment (one replicate well per concentration for Atrazine), per plate, with treatments distributed such that there were equal numbers of interior and exterior (edge) wells for each treatment.&nbsp;Throughout the 24 h exposure period, <em>R. subcapitata</em> were held at 24 °C and kept in suspension by gentle shaking using a temperature controlled orbital shaker (Titramax 1000, Heidolph Instruments GmbH, Schwabach, Germany).</p>	<p><em>R. subcapitata</em> were pooled and extracted using 200 µL of LC-grade Methanol:Acetonitrile:Water (2:2:1) with 5 µg/L 4-Chloro-L-phenylalanine (4CLP; CAS:14173-39-8) serving as an internal standard. After additon of extraction solvent to each well, the microalgae were vortexed for 1 min and kept at -20 °C for 60 min for protein precipitation. After centrifugation (4000 x g, 4 °C, 30 min), the supernatant was collected from the plate to be analyzed for nontargeted metabolomics via LC-HRMS. The extraction included a media blank within the 96 well plate. A quality control (QC) pool was made by combining equal amounts of each extracted media sample (n = 45 total) and solvent blanks was included for LC-MS/MS analysis.</p>	<p>The injection volume was 3 µL per sample with analytes being seperated using a flow rate of 0.400 mL/min under gradient conditions using a Thermo Scientific Vanquish Horizon UHPLC system. The mobile phases included Water + 0.1% Formic Acid (A) and 95% Acetonitrile + 5% Water + 0.1% Formic Acid (B), and the gradient was 1% B from 0.0 to 1.0 min, 50% B at 4.5 min (curve = 6), 100% B at 7.5 min (curve = 6), 100% B at 10.0 min (curve = 5), 1% B at 10.1 min until 14.0 min. The column consisted of an Acquity UPLC HSS T3 1.8 um (2.1 x 100 mm) with a guard column (Acquity UPLC HSS T3 1.8 um VanGuard Pre-Column 2.1 x 5 mm) and in-line filter (Agilent In-Line Filter 2.1 x 0.2 mm) held at a temperature of 40 °C.</p>	<p>The experimental samples were analyzed using non-targeted LC-MS/MS data-dependent acquisition and the QC pool, lab blanks and solvent blanks were also analyzed throughout using an Orbitrap ID-X Tribrid mass spectrometer (Thermo Fischer Scientific, USA) with a heated electrospray&nbsp;interface (H-ESI) operating in positive ionization mode.&nbsp;H-ESI source parameters included sheath gas flow rate = 45, aux. gas flow rate = 10, sweep gas flow rate = 1, spray voltage = 3600 kV, ion transfer tube temperature = 325 °C, vaporizer temperature = 300 °C, and S-lens RF level = 60%. Full-MS1 analysis covered 70-800 m/z range at 60,000 resolution with ACG target set to standard, maximum IT = 50 and microscans = 1. Dynamic exclusion (10 ppm mass tolerance) was set for 2.5 s after 1 time and an intensity threshold of 5.0e4 was used. Top 10 most abundant ions were used for MS2 acquisition at a resolution of 15,000 with an isolation window of 1.5 m/z, HCD stepped = 20, 35 and 50, AGC target = standard, maximum IT = 22 and microscans = 1.</p>	<p>Vendor format raw data files (.RAW) were converted to .mzML file format using ProteoWizard software tool MSConvert. MZmine (version 4.5.0) was used to process non-targeted mass spectrometry data following optimized parameters. Briefly, mass detection MS1 had noise level set to 5 and MS2 set to 2.5. The chromatogram builder had scan filters from 0.5-11.0 min, minimum consecutive scans = 4, minimum intensity = 2.0e3, minimum absolute height = 1e4, m/z tolerance = 10 ppm. Smoothing used Savitzky-Golay algorithm. Local minimum feature resolver had chromatographic threshold = 80.0%, minimum search range RT = 0.05, minimum relative height = 0.0%, minimum absolute height = 1.0e4, min ratio of peaks top/edge = 1.8, peak duration = 0-1.50, and minimum scans = 4. 13C isotope filter had m/z tolerance = 3 ppm, retention time tolerance = 0.04, monoisotopic peak only, maximum charge = 2, representative isotope = most intense, and never remove features with MS2. Isotope peaks finder had chemical element = H, C, N, O and S, m/z tolerance = 3 ppm, maximum charge = 1, and search in scans = single most intense. Feature finder had an intensity threshold = 20.0%, m/z tolerance = 10 ppm, RT tolerance = 0.2, and minimum scans. Duplicate feature filter had m/z tolerance = 1.5 ppm and RT tolerance = 0.05. Feature list blank subtraction (procedural blanks) had minimum of detection in blanks = 2, quantification = area, ratio type = maximum, fold change increase = 300.0%, and remove features below fold change.</p>	<p>MZmine (version 4.5.0) was used for annotating features using the open-source databases MSnLib Mass spectral libraries (https://data.niaid.nih.gov/resources?id=zenodo_11163380), ALL_GNPS_NO_PROPOGATED.mgf (https://external.gnps2.org/gnpslibrary), MassBank_NIST.msp (https://github.com/MassBank/MassBank-data/releases/tag/2024.11), MoNA-export-LC-MS-MS_Positive_Mode.json (https://mona.fiehnlab.ucdavis.edu/downloads), and FragHub_POS_LC.msp (https://zenodo.org/records/12820664). Spectral library search had search for matching MS2 enabled, precursor m/z tolerance = 20 ppm, spectral m/z tolerance = 20 ppm, remove precursor, minimum matched signals = 3, and weighted cosine score = 0.65. Lipid Annotation was also conducted using MZmine with m/z tolerance MS1 level = 5 ppm, lipid classes = all, and search for lipid class specific fragments in MS/MS spectra enabled. SIRIUS (version 6.1.1) was used to annotate the remaining unknown chemical features from non-targeted data-dependent acquisition. Analyses in SIRIUS were performed using default parameters for Orbitrap using de novo and bottom up molecular formula generation and fallback adducts of [M+H]+, [M+Na]+, and [M+K]+. Predicted properties was done using CSI:FingerID and structure database searches including Biocyc, CHEBI, COCUNUT, GNPS, HMDB, LipidMaps, MeSH, PubChem: bio and metabolites. SIRIUS metabolites with confidence score above 0.65 were retained, with the matches to open-source databases superseding the SIRIUS annotation.&nbsp;</p>

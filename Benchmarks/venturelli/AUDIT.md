# Venturelli 2018 data audit

- EV1: 66 пар x 7 точек (1:1), EV2: 15 пар x 2 фазы (95:5/5:95), EV3: 13 сообществ (full+12 dropouts), EV4: 97 метаболитов x 12 видов.
- SBML-модели авторов: ven_s006/twelveSpeciesT1-4.xml (gLV, 12 реакций).
- Транскодинг: Benchmarks/venturelli/task_increments.csv (приращения log-роста).
- Baseline gLV-пара (r, a_ii, a_ij): см. вывод exp070_venturelli_baseline.php.

## Декодинг SBML s006 (19.11)

T1-T4 = линейная gLV в SBML L3V1:
- 12 реакций, kineticLaw вида dx_i/dt = x_i*(r_i + sum_j a_ij*x_j);
- 168 параметров: 12 r + 12x12 матрица a_ij + initial;
- f_i = x_i/sum(x_j) — нормировка для сравнения с 16S-долями;
- ТРОЙНЫХ термов нет ни в T3, ни в T4 (T4 отличается только фитами
  параметров, не структурой).
- OD600/монокультуры в supplementary ОТСУТСТВУЮТ — абсолютные
  численности не восстанавливаются; но T3-проверка авторов шла на
  16S-ДОЛЯХ, значит воспроизведение на долях легитимно.
- Монокультуры не публикованы => r_i/a_ii идентифицируются из пар
  (нелинейность по x_i в 7 точках) — проверять вырожденность.

План reproduction: численный интегратор EV3-композиций с параметрами
T3 (из SBML) -> сравнение с EV3-рядами -> наш аналог T3, фитнутый
на EV1+EV2 (без EV3), -> сравнение с их T3. Потом Assembly.

## B5.2: Воспроизведение T3 (19.11) — УСПЕХ

- Порядок колонок EV3 восстановлен эмпирически из dropout-блоков
  (жадное назначение min-max): BH,CA,BU,PC,BO,BV,BT,EL,FP,CH,DP,ER —
  НЕ совпадает с SBML-порядком, перестановка обязательна (была бы
  молча-ошибка: первые прогоны с неверным маппингом дали R2=-0.39).
- RK4 (dt=0.5h, 6 дней) их T3-параметров от t=0 строк EV3:
  NONE (полное 12-видовое): R2=0.633, корреляция obs~pred = 0.851 —
  совпадает с опубликованной авторами «~0.85 на многовидовых».
  ПОДТВЕРЖДЕНО: SBML-параметры + наш интегратор воспроизводят их
  результат независимо.
- Профиль по видам: PC 0.996, BU 0.591, ER 0.475 — но BH -13.4,
  EL -50.8 (перегиб в хвосте, доля к 0 — gLV-пара не ловит).
  Средний уровень = кросс-видовая корреляция держится на контрастах
  (BU/FP растут, BV/CA/CH падают к 0), а не на точных траекториях
  малых долей.
- Единицы времени: часы (u~0.25-0.9/день, равновесие монокультуры
  за сутки — согласуется с OD-протоколом 12h-точек).

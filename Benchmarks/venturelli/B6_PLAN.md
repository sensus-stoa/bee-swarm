# B6: Полный подъём веса — Venturelli метаболическая композиция

Статус на входе: сигнал измерен и воспроизведён тремя независимыми
процедурами (B5.4 residual z=8.3; B5.8 пер-вид corr 0.4-0.66; B5.10
OOS-прирост +0.102 R2/corr 0.26; B5.12 ER cv=0.115 < порога 0.15,
форма стабильна к floor). Пользователь: «первоначальный гейт показал
что сигнал есть, теперь нужен тяжёлый подъём веса».

## Принятые решения (по трём пунктам пользователя)

1. **Отбор в движок не встраиваем** (отложено; отдельная задача на
   движковый релиз — фич-гейт как first-class стадия Search).
2. **Движок без гейта, на полной грамматике**: прогнать Search::find
   со ВСЕМИ 97 метаболитами как фичами. После фикса грамматики
   (:memory:, 11 базовых опов) OOM вероятен только от размера пула —
   97 фич x depth-2 = ~4.7K pairwise-форм x 11 ops — умеренно; риск
   — L2 pair-loop поверх L1 (~5M). Митигция: (а) pcntl — каждый вид
   в своём процессе; (б) budgetSec щедрый (600-900s/вид); (в) если
   OOM — последовательный перебор метаболитов блоками по 20 с
   агрегацией. Ожидание: best_cv_seen снизится относительно B5.12,
   т.к. движку доступен ВЕСЬ метаболический словарь, а не 5 фич.
3. **Стабильность формы как частичная сертификация**: по канону
   «порог не ослабляем — поднимаем уровень задачи». Стабильность
   найденной формы к (а) floor, (б) стратифицированным сплитам,
   (в) leave-one-dropout-out, (г) перестановочным null — это
   ДОКАЗАТЕЛЬСТВО НЕСЛУЧАЙНОСТИ, отличное от порогового cv.
   Дополнительно: двойной гейт (cv + MDL-компрессия) — форма
   принимается, если она и cv-приемлема, И компрессирует лучше
   нуля/базлайна (MDL: L(данные|форма) + L(форма) < L(данные|нул)).

## План B6 (порядок фиксирован, каждый шаг = коммит с выводами)

### B6.1 Движок на всех 97 фичах (тяжёлый прогон)
- pcntl per-вид; память 4G/процесс; budget 900s; :memory: БД.
- Метрика: best_cv_seen, форма-кандидат, diag. Сравнение с B5.12
  (5 фич) — вопрос: снижает ли полный словарь best_cv?
- Если OOM: fallback на блоки по 20 метаболитов (5 блоков/вид,
  параллельно), агрегация best по блокам; пересечение топ-форм.
- Выход: таблица per-вид {best_cv, форма, floor-стабильность}.

### B6.2 Стабильность формы (частичная сертификация)
- Форма-кандидат ER (m_5-aminovalerate × Rnorm(nicotinamide)) и
  альтернативы из B6.1 — тест на:
  (а) floor-стабильность (0.01/0.02/0.03) — сделано частично в B5.12,
      оформить как таблицу;
  (б) leave-one-dropout-out: фит на 11 dropouts, предсказание 12-й,
      12 фолдов, per-фолд cv формы vs нулевой предиктор;
  (в) стратифицированные сплиты по композициям (3 random seeds),
      распределение cv формы — медиана и разброс;
  (г) перестановочный null формы: 200 перемешиваний EV4-профилей
      (вид ↔ чужой профиль), cv той же формы на ложных фичах —
      если реальный cv лучше null z>=4, форма НЕ артефакт отбора.
- Вердикт: PARTIALLY_CERTIFIED (форма+стабильность) / STRUCTURED
  (нужен только cv-дожим) / FORMLESS.

### B6.3 Двойной гейт: cv + MDL-компрессия
- MDL-механика: L(M) = биты на описание формы (число узлов/опов,
  справочная таблица весов по сложности термов) + биты на остаток
  (log-likelihood гауссовых ошибок). Форма принимается, если
  L(данные|форма)+L(форма) < L(данные|нул)-минимум (нул = медиана
  residual per-вид).
- Пересечение гейтов: форма проходит если cv < 0.15 ИЛИ
  (cv < 0.30 И MDL-выигрыш > 3 bits И стабильно по B6.2).
- Это НЕ ослабление порога: MDL — независимый критерий (компрессия),
  вместе они дают более строгий joint-гейт, чем один cv.

### B6.4 (если B6.2-3 успешны) Сборка в атлас
- Birth B-атома с доменом foraged_venturelli; leave-one-dropout-out
  reuse-тест: рождение на 11, активация на 12-й композиции.
- Потом OMM12 (Weiss 2023) как внешний тест — отдельно, не в фит.

## Риски
- 97 фич x depth-2: L2 pair-loop ~5M пар x 11 ops x 33-72 строки —
  по времени ок в 900s, по памяти контролируем (collect-all $exprs —
  может съесть 4G: тогда блоки).
- Отбор без гейта может вывести не те формы — осознанно: это вопрос
  «что может движок без подсказки» (пользовательский пункт 2).
- MDL-весовая таблица — новая механика: держать простой (узлы+глубина),
  не изобретать сложную теорию информации.

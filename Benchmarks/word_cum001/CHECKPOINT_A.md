# WORD-CUM-001 — CHECKPOINT A: ОТЧЁТ

Дата: 16.10.2026. Вопрос owner: сохраняется ли ссылка `{word,args}` после
допустимой мутации соседнего, не затронутого поддерева, и накапливаются ли
последовательные мутации в одной линии.

## 0. Вердикт

**CHECKPOINT A: PASS.** Ссылка `{word,args}` переживает мутации соседних
поддеревьев байт-в-байт; цепочка из двух мутаций наследуется полностью;
накопленный геном исполняется в чистом процессе. Схема decode → mutate AST →
re-encode подтверждена как ТЕРЯЮЩАЯ ссылки при правке внутри word-области.

## 1. Сценарий (тесты + артефакт)

- Словарь: W1 = BW5737967f… = ((x0+x1)/(x0−x1)) (канон GENOME-001).
- Parent: `(((x0+x1)/(x0−x1))+(x2×x3))` → геном
  `{op:+, l:{word:W1,args:[x0,x1]}, r:{op:×,l:x2,r:x3}}`
  (encoder даёт {word}-ref из pattern-match развёрнутой формы).
- Мутации: минимальная локальная правка узлов генома (рамка owner), сайты детерминированы.

## 3. Схема decode → mutate AST → re-encode (эмпирика, req owner)

| Случай | Поведение re-encode |
|--------|---------------------|
| мутация ВНЕ word-области | ref ВОССТАНАВЛИВАЕТСЯ (subtree по-прежнему матчит W1, аргументы те же) |
| мутация ВНУТРИ word-области | ref ТЕРЯЕТСЯ (подтверждено тестом C4b); содержимое мутации сохранено в raw-форме и исполняется корректно |

Инженерный вывод: накопление ссылок устойчиво ТОЛЬКО при мутации непосредственно
узлов Word Genome (что разрешено и использовано). Проход через decode→AST→
re-encode сохраняет ссылки только пока инстанс слова не тронут; любое касание
внутри слова разворачивает его в raw-поддерево навсегда (в этой линии).

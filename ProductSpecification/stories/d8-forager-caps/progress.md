# Story D8: Forager Caps

> Forager сканирует ВСЕ 1499 файлов рекурсивно, но создаёт только 30 задач

## Реальные ограничения

| Ограничение | Сейчас | Эффект |
|-------------|--------|--------|
| `$maxTotal = 30` | Останавливается после 30 задач | 1499 файлов → 30 задач (2%) |
| Стратегия/файл | Первое совпадение | 10 метрик в отчёте → 1 задача |
| `$size > 500_000` | Пропускает большие файлы | AGENTS.md, дампы — недоступны |

## Spec

1. **`$maxTotal = 30`** → убрать кап. Извлекать ВСЕ паттерны из ВСЕХ файлов
2. **Стратегия внутри файла** — ловит ПЕРВОЕ совпадение, не все. → извлекать все совпадения из каждого файла
3. **`$size > 500_000`** → chunking: разбивать большие файлы на блоки и обрабатывать каждый
4. `RecursiveIteratorIterator` работает — просто убираем кап на задачи
5. Fingerprint фикс уже сделан — не спамит повторами

## Эффект
- 1499 файлов × N паттернов каждый → сотни задач вместо 30
- Каждая метрика (GI, DQ, sleep...) → отдельная задача
- Большие файлы → доступны через chunking

## D7: Новые стратегии

После D8 — нужны стратегии для markdown-метрик:

| Стратегия | Что ловит | Пример |
|-----------|-----------|--------|
| `preg_match_metrics` | Числа после меток | `GI: 7.2` → `gi: 7.2` |
| `preg_match_sleep` | Часы сна | `Сон: 6.5ч` → `sleep_hours: 6.5` |
| `preg_match_jsonl` | JSON-строки метрик | `metrics.jsonl` → все метрики дня |
| `preg_match_delta` | Изменения vs предыдущий день | `Δ GI: +0.5` |

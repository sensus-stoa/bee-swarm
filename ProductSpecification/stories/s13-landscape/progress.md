# Story S1.13-LANDSCAPE: Эпигенетический ландшафт

> Пчёлы становятся «липкими» — специализируются на доменах, накапливают affinity,
> и популяция самоорганизуется в ниши. Эпигенез Уоддингтона для роя.

## Почему

Сейчас: пчела каждый тик получает случайную задачу (`array_rand`). Нет памяти
об успехах, нет специализации. Шар гладкий — катится куда попало.

Надо: шар липкий — приклеивается к тем ниточкам (доменам), где находил золото
(открытия). Со временем разные пчёлы скатываются в разные долины ландшафта.

Из отрывка:
> «липкий шар соберёт много ниточек, они прилипнут к нему и начнут влиять на
> его траекторию... это не случайность, а неизбежная особенность»

## Phases

### Phase 1: Fingerprint affinity — пчела запоминает успешные fingerprint'ы
- [ ] Bee: `$successFingerprints` — массив [fp => count]
- [ ] Bee: `preferFingerprint(string $fp): bool` — вероятность принять задачу с этим fp
- [ ] Hive::doTick: после `taskRouter->route()`, пчела может ОТКЛОНИТЬ задачу если fp незнаком
- [ ] Параметр: `affinityThreshold` — после N успехов на fp, пчела предпочитает этот fp
- [ ] **E2E:** через 100 тиков пчёлы по-разному реагируют на `metrics` vs `logic` vs `foraged`
- [ ] **E2E-индикатор:** diversity растёт, каждая пчела имеет уникальный профиль fp

### Phase 2: Grammar fitness — spawn наследует предпочтения родителя
- [ ] Bee: `fitness` — per-domain счётчик успехов
- [ ] Bee::spawn: ребёнок наследует `$successFingerprints` и `$fitness` родителя (с мутацией)
- [ ] Bee: `getAffinity(string $domain): float` — нормированный счётчик успехов
- [ ] **E2E:** 2-е поколение пчёл сохраняет специализацию родителя
- [ ] **E2E-индикатор:** `GEN: 1` логи показывают дочерних пчёл с унаследованным affinity

### Phase 3: Ниши — доменная специализация
- [ ] Hive: `domainNiches` — отслеживание доминирующих доменов в популяции
- [ ] Hive::doTick: при DEATH пчелы — её ниша освобождается
- [ ] Hive::doTick: при SPAWN — ребёнок может занять нишу родителя или новую
- [ ] **E2E:** после 500+ тиков формируются устойчивые ниши: `metrics-специалисты`, `logic-специалисты`
- [ ] **E2E-индикатор:** `GEN: N` показывает `unique` grammar count стабилизируется (не растёт бесконечно)

## Архитектура

```
Bee
  ├── $successFingerprints: array [fp => count]
  ├── $fitness: array [domain => score]
  ├── preferFingerprint(fp): bool          // хочу эту задачу?
  └── spawn() → child наследует affinity    // липкость передаётся

Hive::doTick
  ├── TaskRouter::route(task) → bee
  ├── bee->preferFingerprint(fp)             // пчела решает: брать?
  │   ├── YES → поиск → reward/punish
  │   └── NO  → перемаршрутизация на другую пчелу
  └── GEN: логируют diversity + niche distribution
```

## Что НЕ делать
- ❌ Не хардкодить домены (metrics, logic, text) — fingerprint структурный
- ❌ Не блокировать пчелу намертво — 20% случайных задач для exploration
- ❌ Не усложнять Bee без тестов — каждый метод RED→GREEN

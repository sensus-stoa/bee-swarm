# S2.7-ACCUMULATOR-DECOMPOSE — декомпозиция StreamingAccumulator

> V0.8.5 follow-up. 4 бага найдено в монолитном scan().
> Цель: изолировать этапы сканирования в тестируемые методы.

## Мотивация

`StreamingAccumulator::scan()` — 235 строк, 5 этапов:

| Этап | Строки | Баги найдены |
|------|--------|-------------|
| 1. Итерация файлов + фильтры | 30 | #4 (outer catch убивал цикл) |
| 2. Применение стратегий | 35 | — |
| 3. Применение текст-атомов | 25 | #1 (non-numeric), #3 (PRIMARY KEY) |
| 4. Bootstrap-задача | 5 | — |
| 5. GROUP BY + построение задач | 25 | #3 (GROUP BY считал уникальные, не файлы) |

Без декомпозиции каждый баг требовал часовой охоты с патчами на ноутбуке.

## Фазы

### Phase 1: Выделить buildTextAtomEntries()
- Изолировать этап 3 (применение текст-атомов к одному файлу)
- Сигнатура: `buildTextAtomEntries(PDO $stmt, string $content, string $path, string $colLabels, string $contentSample): int`
- Возвращает количество вставленных строк в fd
- Тест: fixture-файл → проверить число строк в fd

### Phase 2: Выделить buildStrategyEntries()
- Изолировать этап 2 (применение стратегий к одному файлу)
- Сигнатура аналогична Phase 1
- Тест: fixture-файл → проверить число строк

### Phase 3: Выделить buildTasks()
- Изолировать этап 5 (GROUP BY + формирование tasks[])
- Сигнатура: `buildTasks(PDO $db): array`
- Тест: заполнить fd вручную → проверить tasks

### Phase 4: scan() вызывает выделенные методы
- scan() становится оркестратором: итерация + вызов build* + buildTasks
- < 80 строк
- Все существующие тесты проходят

## Оценка
2.5 часа. Priority: High (после V0.8.5).

# S3.7 — Compression-Driven Discovery (теоретическая)

## Статус: ⬜ Theoretical | Stage 3+

## Идея

CV→0 сейчас требует target: X → f → ŷ. Сжатие не требует target: X → f → X'.
Критерий: size(compressed) < size(original). Пчела находит transform который
уменьшает размер данных → обнаружила структурную избыточность.

## Применение

- Изображения: найти что JPEG-блоки 8×8 — оптимальный размер
- Бинарные форматы: найти что ELF-заголовки имеют фиксированную структуру
- Текст: найти что повторяющиеся n-граммы сжимаются лучше случайных
- Аудио: найти что частота дискретизации 44.1kHz избыточна для речи

## Необходимая инфраструктура (не реализована)

- ImageForager: читает байты, отдаёт матрицы пикселей
- AudioForager: читает WAV, отдаёт MFCC/спектрограммы
- BinaryForager: читает ELF/PE, отдаёт структурные поля
- Compression fitness: вместо CV → size_ratio

## Связь с протоколом

Протокол §1.7: «Compression superiority — найденный закон сжимает данные лучше чем
тривиальная модель.» Сжатие — частный случай этого принципа где target = сами данные.

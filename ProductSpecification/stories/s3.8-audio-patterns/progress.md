# S3.8 — Audio Pattern Discovery (теоретическая)

## Статус: ⬜ Theoretical | Stage 3+

## Идея

Звук содержит повторяющиеся акустические паттерны. CV→0 может найти их как инварианты:
форманты, слоги, паузы, интонационные контуры. Без разметки (unsupervised).

## Что реально

1. **Акустические инварианты:** MFCC-признаки → Search::find находит повторяющиеся
   комбинации частот. CV→0 подтверждает что паттерн стабилен на held-out отрезках.
   Это НЕ слова. Это «атомы звука» — аналоги BASE_OPS для аудио.

2. **Cross-domain bridge (амбициозно):** если есть транскрипт + аудио →
   акустический атом + текстовый концепт → CV→0 валидирует связь.
   «Форманта F2:850Hz + длительность 120ms → слово 'привет' с CV=0.08».

3. **Compression:** аудио-файл → transform → меньший размер = найден redundancy.
   Пчела обнаружила что 44.1kHz избыточна для речи → реальный закон.

## Что НЕ реально

- Распознавание речи без обучения. CV→0 не заменяет supervised learning.
- Понимание смысла. Это классификация звуков, не семантика.

## Необходимая инфраструктура

- AudioForager: читает WAV/MP3, извлекает MFCC/спектрограмму/темп
- Segmentation: Voice Activity Detection, разбивка на фонемы/слоги
- Акустическая грамматика: formant_ratio, duration, pitch_slope, energy_floor

## Связь с существующим

Ближайший аналог — E1-FIX (текст-атомы). Forager извлекает match_label из текста.
AudioForager извлекает formant_pattern из аудио. Тот же pipeline:
forager → task → Search::find → law.

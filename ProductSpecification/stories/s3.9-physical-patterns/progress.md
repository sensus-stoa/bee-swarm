# S3.9 — Physical Pattern Discovery (теоретическая)

## Статус: ⬜ Theoretical | Stage 3+

## Идея

Физический мир полон инвариантов. CV→0 может их найти без supervised learning —
через сенсоры (вибрация, температура, акселерометр, LIDAR, камера).

## Домены

### 1. Вибрационные инварианты (predictive maintenance)
- Акселерометр → временной ряд → Search::find
- «Частота 120Hz + амплитуда > 0.5 → износ подшипника с CV=0.03»
- Не нужна разметка «сломается/не сломается» — аномалия сама выбьется из CV

### 2. Пространственные инварианты (карта дома)
- LIDAR/камера → 3D-точки → Search::find
- «Стена перпендикулярна полу → угол 90° ± 2° (CV=0.01)»
- «Дверь соединяет ровно 2 комнаты (CV=0.00)»
- Система строит карту не через SLAM, а через поиск геометрических законов

### 3. Embodied invariants (самовосприятие)
- Свои же сенсоры → данные → закон о себе
- «При движении вперёд акселерометр X растёт, Y падает (CV=0.05)»
- «При падении — пик по всем осям одновременно»
- Это grounding: символ «падение» привязан к физическому сигналу

### 4. Мультимодальные инварианты
- Камера + микрофон + акселерометр → cross-modal законы
- «Когда камера видит дверь, шагомер показывает 0 — стою (CV=0.02)»
- «Когда микрофон слышит 'стук', акселерометр показывает вибрацию (CV=0.01)»

## Необходимая инфраструктура

- SensorForager: универсальный читатель сенсорных данных
- SpatialGrammar: distance, angle, perpendicular, coplanar, contains
- TemporalGrammar: frequency, amplitude, period, phase, envelope
- CrossModalForager: синхронизация временных меток между сенсорами

## Связь с протоколом

Протокол §3.7 (Model of Consequences): система обнаруживает причинно-следственные связи
между действиями и выживанием. Physical patterns — necessary precursor:
сначала система находит что «вибрация = движение», потом что «движение вперёд = заряд батареи падает».
